# 루트를 한국어로 · 영어는 /en plan

- 생성: 2026-11-10 18:40

## 목표

AdSense 심사가 "사이트가 다운되었거나 사용할 수 없음"으로 거절됐다. 신청 URL `/`가 내용 없이 JS로 `/ko/`·`/en/`에 이동만 하는 페이지라서로 판단했다. 그래서 주소 구조를 바꾼다.

| 전                        | 후                               |
| ------------------------- | -------------------------------- |
| `/` 언어 선택·이동 페이지 | `/` 한국어 홈 (이동 없음)        |
| `/ko/`, `/ko/privacy/`    | `/`, `/privacy/` — 옛 주소는 301 |
| `/en/`, `/en/privacy/`    | 그대로                           |

- 언어 자동 이동은 없앤다(사용자 결정: 페이지 이동은 원하지 않음). 언어는 헤더 KO/EN 버튼으로 바꾼다.
- 영어 페이지는 별도 주소(`/en/`)로 남아 검색에 따로 노출된다. hreflang `ko`=`/`, `en`=`/en/`, `x-default`=`/`.
- 단일 주소에서 언어만 바꾸는 방식은 영어 페이지가 검색에 노출되지 않아 채택하지 않았다.

## 구조

- 루트 레이아웃 두 개(라우트 그룹): `(ko)` → `/`, `/privacy/`, `(en)` → `/en/`, `/en/privacy/`. 404는 지금처럼 `global-not-found`.
- 두 그룹이 같은 내용을 쓰도록 공통 부분을 한 곳에 모은다: 메타데이터, html·헤더·푸터 틀, 홈·방침 본문(`src/site/`).
- 경로 규칙은 `lib/i18n.ts`의 `localePath(locale, path)` 하나로 통일한다(ko는 접두어 없음, en은 `/en/`).
- 고른 언어를 기억하던 localStorage 키는 쓸 곳이 없어 삭제한다.
- `public/_redirects`: `/ko/*` → `/:splat` 301.
- GTM은 `/`에도 들어간다. 지금까지는 `/`가 이동 페이지라 GTM이 없었다.
- lotto-rich 웹의 개인정보처리방침 링크 `/ko/privacy/` → `/privacy/`. 301이 있으니 급하지는 않지만 바로 맞춘다.
